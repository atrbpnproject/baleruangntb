# Panduan Unggah GitHub

## Website

- Buka GitHub Desktop.
- Pilih **File → Add Local Repository**.
- Pilih folder `D:\DATA KSB\APLIKASI\BALE-RUANG-NTB-GITHUB`.
- Jika diminta, pilih **Create a Repository**.
- Commit seluruh file, lalu tekan **Publish Repository**.
- Repository harus Public agar GitHub Pages tersedia pada akun GitHub Free.

## GitHub Pages

Di GitHub buka **Settings → Pages**, lalu pilih branch `main` dan folder `/ (root)`.

## Data mentah

Buka **Releases → Draft a new release**, gunakan tag `data-2026.09`, lalu unggah isi folder `D:\DATA KSB\APLIKASI\BALE-RUANG-NTB-RELEASES`.

## Penting

Jangan menyalin `data/source` ke branch `main`. Jangan mengubah atau mengekstrak berkas `.js.gz`; aplikasi membukanya otomatis secara lossless.
